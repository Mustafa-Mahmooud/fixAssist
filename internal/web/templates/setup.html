Auto-fix high-impact issues (optional, Claude Code)

When a high-impact issue comes in, Fix Assistant emails you an Auto-fix this button. Once you approve, a small program on your computer runs Claude Code on the fix in a separate branch (your own checkout is never touched), opens a pull request, and turns on auto-merge, so it merges once your checks pass. After the merge, Fix Assistant watches for the error on the new version as usual and tries again, up to {{$.Data.MaxAttempts}} times, if it comes back.

You need Claude Code, git and the GitHub CLI (gh auth login) on that computer. Your code stays on your computer. One fix runs at a time.

1. Connect the computer that has your app's code. One command installs fixassist (the small helper that does the fixing), connects your code folder to this app and keeps it running in the background.

{{if $.Data.PairCode}}

Open a terminal in your app's code folder (the one you cloned from GitHub) and paste the line for your computer. It works once, in the next 15 minutes.

Windows (PowerShell):

irm "{{$.Data.ServerURL}}/install/fixassist.ps1?pair={{$.Data.PairCode}}" | iex

Mac or Linux (Terminal):

curl -fsSL "{{$.Data.ServerURL}}/install/fixassist.sh?pair={{$.Data.PairCode}}" | sh

It checks for Claude Code, git and the GitHub CLI and tells you what's missing. When it finishes, refresh this page: your computer shows up under "Connected computers".

{{else}}
{{end}}
Or set it up by hand

Install fixassist. On Windows, paste this into PowerShell:

irm {{$.Data.ServerURL}}/install/fixassist.ps1 | iex

On a Mac or Linux, paste this into Terminal:

curl -fsSL {{$.Data.ServerURL}}/install/fixassist.sh | sh

Or download it yourself: {{range .Downloads}}{{.Label}}{{end}}

Create an agent token above, then connect fixassist to this app's code and start it:

fixassist add --server {{$.Data.ServerURL}} --token {{if $.Data.NewToken}}{{$.Data.NewToken}}{{else}}<your agent token>{{end}} --repo /path/to/your/app
fixassist install

fixassist install keeps it running in the background with no window: it starts by itself when you log in and restarts if it stops. fixassist status shows what it's doing; fixassist uninstall stops it.
