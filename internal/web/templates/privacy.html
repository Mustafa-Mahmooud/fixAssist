Privacy policy

Effective 25 November 2026

Fix Assistant helps founders find and fix the errors in their apps. To do that, it collects error reports and basic visit data from the apps it's installed on, and removes personal details before anything is stored. This page explains exactly what is collected, why, how long it's kept, and who handles it.

There are two groups of people involved:

  • Customers: the founders and teams who create a Fix Assistant account and install it on their app.
  • Visitors: the people who use a customer's app. Fix Assistant processes their data on behalf of the customer, who decides to install it and is responsible for telling their visitors (see For customers).

2. Data from the apps Fix Assistant is installed on

When a customer installs the Fix Assistant script on their website (and, optionally, an error-reporting package on their server), it sends:

WhatDetails
Error reportsThe error's type and message, where in the code it happened (stack trace), the page or request path, the browser and device type, and the app version. For failed requests: the method, address, status code and up to 2 KB of the response, after cleaning.
Page viewsThe page path, how long it took to load, the device type (desktop, mobile, tablet), the app version, and a random ID for the browser tab that ends when the tab is closed.
Clicks and sign-upsThe label of buttons and links that were clicked, and whether a sign-up or login succeeded. What people type into forms is never collected.
CountryWorked out from the IP address when the data arrives, using an offline database (DB-IP). IP addresses of page views are never stored. On error reports, IP addresses are shortened (the last part removed) before storing.
Daily visitor countTo count unique visitors without cookies, Fix Assistant computes a one-way code from the IP address, browser and date, mixed with a secret per app. It changes every day and can't be turned back into an IP address or used to follow someone across days.

What is removed before anything is stored

Personal details are removed twice: in the visitor's browser, and again on our server. This covers:

  • email addresses, passwords, login tokens, API keys and card numbers found in messages and data;
  • the values in web addresses (for example ?email=...; the field names are kept);
  • cookies, authorization headers and request bodies;
  • on servers, the values of local variables and the server's environment;
  • user IDs set by the app, which are replaced with a one-way code unique to that app.

Customers who need it can also turn off visit tracking entirely, so only errors are sent.

3. Customers' code (optional)

If a customer connects a GitHub repository, Fix Assistant gets read-only access to the repositories they choose. When it explains an error, it reads the code in memory to find the relevant file. It keeps only the file path, the line number and a snippet of up to 120 characters. Code is never stored or shared. The customer can disconnect at any time, from Fix Assistant or from GitHub.

4. How the data is used

  • To group errors into issues, explain them, and write fix suggestions for the customer.
  • To send the customer the alerts, daily summaries and weekly ideas they receive.
  • To check whether a fix worked, after the customer publishes it.
  • To show the customer traffic statistics for their own app.
  • To improve fix suggestions across all apps. For this, only the pattern of an error (for example "value too long for a database column") and counts of how often a fix worked are shared between apps. No visitor data, error details or customer names are shared, and other apps only ever see totals.
  • To train Fix Assistant's own AI model, which writes suggestions for errors it hasn't seen before. For each suggestion it keeps a cleaned copy of the error details, the suggestion, what the customer's coding agent changed (its summary and the file names) and whether the fix worked. Emails, IP addresses, keys, tokens and other secrets are removed first. The model runs on servers Fix Assistant rents, and this data isn't given to anyone else. It is kept until the customer turns this off in the project's Setup page ("Help improve fix suggestions"), which also deletes what was kept, or deletes the project.

Fix Assistant doesn't sell data, doesn't show ads, and doesn't use AI models from other companies to process your data.

5. Cookies and browser storage

  • On Fix Assistant's own website: one cookie to keep you signed in (30 days), and a short-lived cookie (10 minutes) while you sign in with GitHub. Both are needed for the service to work. No advertising or tracking cookies.
  • On customers' apps: the script sets no cookies. It keeps a random tab ID in the browser's session storage, which is cleared when the tab is closed. Only if the customer turns it on (after asking their visitors' consent) does it also keep a random visitor ID in the browser's local storage, for more accurate returning-visitor counts.

7. How long data is kept

  • Raw error reports, page views and clicks: 30 days, then deleted automatically.
  • Issues (the grouped errors, with up to 20 cleaned example reports each), fix suggestions and daily statistics: for as long as the customer's project exists.
  • Model training data (cleaned, see section 4): until the customer turns it off or deletes the project.
  • Sign-in links: 15 minutes (or until used). Sessions: 30 days.
  • Accounts: until the customer asks for deletion.

8. Security

All traffic is encrypted (HTTPS). The database is not reachable from the internet. Session cookies and agent tokens are stored only as one-way hashes. The keys of the GitHub App are stored encrypted. Each customer can only see their own projects.

9. Your rights

You can ask to see, correct, export or delete your data, or object to how it's used, by emailing {{.Data.Contact}}. Requests are answered within 30 days.

  • Customers can also ask for a project or their whole account to be deleted, including all of its data.
  • Visitors of an app that uses Fix Assistant should first contact that app's owner, who controls the data. Because Fix Assistant removes personal details and doesn't use cookies to identify people, it usually can't link stored data to a specific visitor. If you write to us, we'll help however we can.

Depending on where you live (for example in the EU, the UK or Egypt), you may also have the right to complain to your data protection authority.

10. For customers: telling your visitors

If you install Fix Assistant on your app, you're responsible for telling your visitors in your own privacy policy. You can adapt this text:

We use Fix Assistant to find and fix errors in our app. When an error happens, or when you view a page, it receives technical information such as the error message, the page address, your browser and device type, and your approximate country. Personal details like email addresses and passwords are removed before anything is stored, IP addresses are not stored, and no cookies are used. This information is kept for 30 days. 11. Children

Fix Assistant is a tool for businesses and isn't meant for children. Customer accounts are for people aged 16 or older.
